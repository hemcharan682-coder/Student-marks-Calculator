# Student Marks Calculator

My first Python project as a B.Sc. CSAI student.

## About
A simple Python program that calculates a student's
total marks and average across three subjects.

## Features
- Takes the student's name
- Accepts marks for three subjects
- Calculates total marks
- Calculates average marks
